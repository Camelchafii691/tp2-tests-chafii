# TP 2 — Tests LangChain4j

Camel Chafii — EMSI CASA-IA G2.

Première partie uniquement : programmes Java en console, un programme par test.
Énoncé : http://richard.grin.free.fr/emsi/casablanca-ia/tp/tp2-langchain4j/index.html

## Prérequis

JDK 25, Maven et une clé Gemini dans la variable d’environnement `GEMINI_API_KEY`.
La clé doit être configurée dans le terminal ou dans les variables de la configuration d’exécution IntelliJ, jamais dans le code ni dans Git.

Les versions LangChain4j proviennent de la même release : 1.23.0 / 1.23.0-beta33.
